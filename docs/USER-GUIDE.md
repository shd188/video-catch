# 渠道版扩展 · 用户使用说明

本文面向**最终用户**（已购买或获得渠道扩展包与激活码的客户），说明如何在 Chrome / Edge 中安装、激活、下载视频，以及如何升级版本。

当前支持的渠道示例：

| 渠道 | 扩展名称 | 适用网站 |
|------|----------|----------|
| 小鹅通 | 小鹅通视频下载 | H5（`*.h5.xiaoeknow.com`）、PC（`*.xet-pc.citv.cn`、`*.pc.xiaoe-tech.com` 等） |
| 腾讯会议 | 腾讯会议视频下载 | 腾讯会议 Web（`meeting.tencent.com` 等） |
| 飞书 | 飞书视频下载 | 飞书 Web（`*.feishu.cn`、`*.larkoffice.com` 等，见渠道白名单） |

不同渠道是**多个独立扩展**，可同时安装，互不替换。

---

## 一、使用前准备

### 1.1 浏览器

- 推荐使用 **Google Chrome** 或 **Microsoft Edge**（版本建议 104 及以上）。
- 本扩展为**开发者模式侧载安装**，不会出现在 Chrome 网上应用店；这是正常现象。

### 1.2 您应收到的内容

向服务商索取时，通常包括：

1. **扩展安装包**：`xiaoetong.zip`、`tencentmeeting.zip` 或 `feishu.zip`（解压后得到同名文件夹）。
2. **激活码**：格式类似 `CC-XXXX-XXXX-XXXX`，**每个设备首次使用需要激活一次**。
3. **本说明**：在线阅读链接（示例）<https://api.shentongxue.online/guide/>（以服务商实际域名为准）。

> 请仅下载您有权访问、备份或学习的课程内容，遵守平台服务条款与著作权法。

## 二、安装扩展（首次）

### 2.1 解压安装包

1. 将收到的 zip 保存到电脑（例如「下载」文件夹）。
2. 双击解压，得到文件夹，例如：
   - 小鹅通：`xiaoetong`
   - 腾讯会议：`tencentmeeting`
   - 飞书：`feishu`

请**记住这个文件夹的完整路径**，升级时还要覆盖同一目录。

### 2.2 在浏览器中加载

1. 地址栏输入 `chrome://extensions` 并回车（Edge 可用 `edge://extensions`）。
2. 打开右上角 **「开发者模式」**。
3. 点击 **「加载已解压的扩展程序」**。
4. 选择刚才解压的文件夹（如 `xiaoetong`），不要只选 zip 文件本身。

加载成功后，扩展列表中会出现对应名称（如「小鹅通视频下载」）。

### 2.3 首次打开的说明页

首次安装会自动打开 **安装说明页**，内容包括：

- 免责声明与隐私说明  
- **渠道激活**（见下一节）  
- GPL 开源许可说明  

阅读后点击 **「我已阅读」** 关闭即可。

---

## 三、激活（每个设备只需一次）

1. 在安装说明页的 **「渠道激活」** 区域，输入服务商提供的激活码。
2. 点击 **「激活」**，看到「激活成功」即可。
3. 关闭说明页，扩展即可正常使用。

说明：

- **同一台电脑、同一浏览器配置文件** 激活一次后，后续**版本升级无需重新输入激活码**。
- 激活码通常绑定设备数量上限；换电脑或重装系统后，可能需要在另一台设备上再次激活（以服务商政策为准）。
- 若提示「激活码无效」「已使用」「不适用于本渠道」等，请联系服务商核对码与渠道是否匹配。

## 四、日常使用：嗅探与下载

### 4.1 打开正确的网页

渠道版仅在**白名单网站**上工作。例如：

- **小鹅通**：在浏览器中打开店铺课程页（H5 常见 `*.h5.xiaoeknow.com`，PC 常见 `*.xet-pc.citv.cn` 或 `*.pc.xiaoe-tech.com`），进入直播回放或点播页面，**开始播放视频**。
- **腾讯会议**：打开会议回放页面（`meeting.tencent.com` 相关链接），播放回放。
- **飞书**：在飞书 Web 端打开视频或课程页（常见 `*.feishu.cn`、`*.feishu.net`、`*.larkoffice.com` 等白名单域名），**开始播放视频**。

### 4.2 查看扩展是否生效

点击浏览器工具栏上的扩展图标，打开 **弹出窗口（Popup）**：

- 顶部会显示渠道名称。
- 若显示 **「当前页面在白名单内，可嗅探」**，表示本页可以抓取资源。
- 若显示 **「不在白名单内」**，请确认是否打开了正确的课程/回放地址。
- 若显示 **「尚未激活」**，请回到安装说明页完成激活。

列表区域会显示嗅探到的媒体链接；若暂时没有，可**刷新页面并播放几秒视频**后再看。

### 4.3 下载单个视频（常见：m3u8 课程）

1. 在 Popup 资源列表中找到目标条目（类型多为 m3u8 或 mp4）。
2. 点击该条目的 **「下载」** 按钮（或解析/下载图标）。
3. 点击 **「合并下载」**，等待进度完成，文件会保存到浏览器默认下载目录。

> 视频较长时请耐心等待；合并过程中请勿关闭解析器标签页。

### 4.4 其它下载方式（可选）

- **直接下载**：部分 mp4 等资源可一键下载，无需进入解析器。
- **复制链接**：可复制地址后用其它下载工具处理（需您自行合规使用）。
- 更多高级功能（合并多段、调用外部工具等）见扩展 **设置** 页；渠道版已对部分选项做了锁定，以保障稳定与安全。

## 五、版本升级

当服务商发布新版本时，扩展 Popup 或浏览器可能提示 **「发现新版本」**。

### 5.1 升级特点

- **无需重新激活**（本设备此前已激活过同一渠道）。
- 请**覆盖原安装目录**，不要在全新文件夹里再「加载已解压」，否则可能被识别为另一个扩展，导致重复安装或激活数据不一致。

### 5.2 推荐步骤（方法 A）

1. 在升级提示中点击 **「下载更新」**，保存为 `xiaoetong.zip`、`tencentmeeting.zip` 或 `feishu.zip`（文件名无版本号，属正常）。
2. 解压 zip，得到 `xiaoetong`、`tencentmeeting` 或 `feishu` 文件夹。
3. 打开您**当初加载扩展时选中的那个文件夹**（路径与首次安装相同）。
4. 用解压出的文件夹**内所有文件**覆盖原目录（替换同名文件）。
5. 打开 `chrome://extensions`，找到对应扩展，点击 **「重新加载」**（圆形箭头）。
6. 确认版本号已更新，继续正常使用即可。

也可点击升级页中的 **「打开扩展管理页」** 快速跳转。

## 六、同时安装多个渠道

若您同时拥有 **小鹅通**、**腾讯会议** 与 **飞书** 等多个渠道包：

1. 分别解压为 `xiaoetong`、`tencentmeeting`、`feishu` 等文件夹（路径可不同）。
2. 在 `chrome://extensions` 中**分别**「加载已解压」两次，各选一个文件夹。
3. 工具栏会出现多个扩展图标；各自激活码独立，各自仅在自己的白名单网站生效。

## 七、常见问题

### 安装后找不到视频？

| 可能原因 | 处理办法 |
|----------|----------|
| 未完成激活 | 打开安装说明页输入激活码 |
| 当前网页不在白名单 | 换到课程 H5 / 回放页；看 Popup 顶部提示 |
| 视频尚未开始播放 | 先播放几秒再打开 Popup 刷新列表 |
| 扩展被关闭 | 在 `chrome://extensions` 确认扩展已启用 |


### 升级后又要激活？

请勿在新文件夹重复「加载已解压」。应**覆盖原目录 + 重新加载**。若仍异常，联系服务商检查是否换用了错误的 zip 或新浏览器配置文件。

### 提示无法连接激活服务器？

需能访问服务商配置的 API 地址（需 HTTPS）。检查网络、代理或防火墙；仍失败请联系服务商。

### 下载失败或文件无法播放？

- 确认课程已完整加载、网络稳定。  
- 尝试减小解析器中的「下载线程」或分段下载。  
- 加密特殊的流可能不支持，请联系服务商反馈页面地址（勿传播未授权内容）。
