# 隐私说明（订阅服务）

## 扩展本地处理

渠道版扩展默认在本地嗅探与列出媒体，不把页面内容上传到开发者服务器。

## 若启用订阅 API（`license.apiBase`）

扩展可能向你的 API 发送：

| 数据 | 用途 |
|------|------|
| 激活码 | 校验订阅 |
| `installation_id`（随机 UUID） | 设备数量限制 |
| 扩展版本号 | 判断是否有更新 |
| User-Agent | 排错（可选） |

**不会**默认上传浏览的 URL 列表或媒体文件。

## 服务端运营方

若你部署 `server/`，你作为控制者应：

- 在售卖页提供本说明或等价隐私政策  
- 仅收集实现激活、更新通知所需的数据  
- 妥善保管 `licenses.db`，定期备份
