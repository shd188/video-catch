1. 下载安装包

请按你的电脑系统与芯片下载对应版本，不要混用。

macOS

当前系统

安装包：.dmg（Apple 芯片 / Intel 芯片分开）

下载 Apple 芯片版 当前芯片 下载 Intel 芯片版 当前芯片
  1. 不确定芯片时：左上角 → 关于本机（写「芯片」= Apple，写「处理器」且带 Intel = Intel）
  2. 打开下载的 DMG，拖到「应用程序」
  3. 若被拦截：系统设置 → 隐私与安全性 → 仍要打开

Windows

当前系统

安装包：.exe

下载 Windows 版
  1. 运行下载的安装程序
  2. 若 SmartScreen 拦截：点「更多信息」→「仍要运行」
  3. 安装完成后从开始菜单打开软件

2. 激活软件

  1. 打开软件，复制窗口里的本机机器码
  2. 打开 激活页面，填写小红书订单号和机器码并提交（会写入数据库）
  3. 把网页显示的激活码粘贴回软件完成验证（软件里不用再填订单号）
去激活 查看教程

注意事项

  • 一个激活码只能绑定一台电脑。卖家作废后，用同一订单号重新提交可领取新码。
  • 未作废前更换电脑需联系卖家解绑或作废后重新激活。
  • 请仅下载你已付费、有权观看的课程内容。
  • Windows 请用 Chrome 或 Edge 打开本站，不要用微信 / QQ 内置浏览器。软件里若提示网络错误，把本页地址复制到浏览器打开即可领取激活码。
