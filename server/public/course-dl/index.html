1. 下载安装包

请按你的电脑系统下载对应版本，不要混用。

macOS

当前系统

安装包：.dmg

下载 Mac 版
  1. 打开下载的 DMG
  2. 把「小鹅通课程下载器」拖到「应用程序」
  3. 若被拦截：系统设置 → 隐私与安全性 → 仍要打开

Windows

当前系统

安装包：.exe

下载 Windows 版
  1. 运行下载的安装程序
  2. 若 SmartScreen 拦截：点「更多信息」→「仍要运行」
  3. 安装完成后从开始菜单打开软件

2. 领取激活码

  1. 打开 领取页面，填写小红书订单号（P 开头 + 18 位数字，共 19 位）
  2. 点击「生成激活码」，页面会显示你的激活码（可复制）
  3. 打开软件，把激活码粘贴进去完成绑定
去领取激活码 查看教程

注意事项

  • 一个小红书订单号只能领取一次激活码；一个激活码只能绑定一台电脑。
  • 换电脑请联系卖家解绑或更换激活码。
  • 请仅下载你已付费、有权观看的课程内容。
