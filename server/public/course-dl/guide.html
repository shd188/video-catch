下载安装

在首页按系统选择——Mac 用 macOS（.dmg），Windows 用 Windows（.exe），不要混用。

Windows 安装与激活

  1. 双击下载的程序包进行安装。
  2. 打开应用程序，显示激活页面。
  3. 复制本机机器码，点击打开激活网页。
  4. 输入小红书订单号和刚刚复制的机器码，提交后获得激活码。
  5. 返回软件，粘贴激活码，完成激活。

Mac 安装与激活

  1. 双击打开 .dmg（窗口标题为「安装程序」）。
  2. 方法一：双击【安装并打开】，会复制并自动弹出应用程序窗口。
  3. 方法二：把左侧软件拖到右侧「应用程序」文件夹，再双击该文件夹即可看到。

Mac 首次安装可能会提示失败：系统检测到安装包不是 App Store 下载的软件。请到【系统设置】→【隐私与安全性】，把「允许以下来源的应用程序」改为 App Store 与已知开发者，并允许打开「小鹅通课程下载器」。

  1. 打开应用程序，显示激活页面。
  2. 复制本机机器码，点击打开激活网页。
  3. 输入小红书订单号和刚刚复制的机器码，提交后获得激活码。
  4. 返回软件，粘贴激活码，完成激活。

开始使用

  1. 打开浏览器登录：在软件中点击「打开浏览器登录」，用微信/手机号登录小鹅通（或店铺自定义域名）。
  2. 粘贴课程链接：打开专栏/课程的「目录」页，复制浏览器地址栏链接，粘贴到软件。
  3. 开始下载：选择保存目录，点击开始下载。视频按原标题保存；资料在课程文件夹的「资料」子目录。

若提示需要登录：请先在弹出的浏览器窗口完成登录，软件会自动继续。

常见问题

  • 激活码已在其他设备使用：一码一台电脑，若更换电脑需重新购买。
  • 订单号已激活过：同一小红书订单号会绑定同一份激活码。
  • 读不到目录：确认在软件弹开的浏览器进行登录，视频可以正常播放，且打开的是目录页（不是纯商品购买页）。
