文字教程

  1. 下载安装：在首页按系统选择——Mac 下 macOS（.dmg），Windows 下 Windows（.exe），不要混用。
  2. 激活：打开软件复制机器码 → 打开「激活软件」页，填写小红书订单号和机器码并提交 → 把网页显示的激活码粘贴回软件（不必再填订单号）。
  3. 打开浏览器登录：在软件中点击「打开浏览器登录」，用微信/手机号登录小鹅通（或店铺自定义域名）。
  4. 粘贴课程链接：打开专栏/课程的「目录」页，复制浏览器地址栏链接，粘贴到软件。
  5. 开始下载：选择保存目录，点击开始下载。视频按原标题保存；资料在课程文件夹的「资料」子目录。

若提示需要登录：请先在弹出的浏览器窗口完成登录，软件会自动继续。

常见问题

  • 激活码已在其他设备使用：一码一台电脑，若更换电脑需重新购买。
  • 订单号已激活过：同一小红书订单号会绑定同一份激活码；换电脑需联系卖家解绑。
  • 读不到目录：确认已登录，且打开的是目录页（不是纯商品购买页）。
